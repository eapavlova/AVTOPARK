## Непроверенные внешние условия

- Docker на компьютере недоступен. Локальный PostgreSQL найден, но предоставленные проектные учетные данные им не приняты, поэтому миграции на живой базе пока не проверены.
- Не предоставлены домен портала, код и секрет локального приложения Bitrix24.
- Вход через реальный портал Bitrix24 пока не проверялся; автоматические тесты используют имитацию ответов REST API.
- Для установки в Bitrix24 нужен публичный адрес HTTPS; `127.0.0.1` портал открыть не сможет.
- Перед переносом на сервер нужно включить каталог `FILE_STORAGE_DIR` в резервное копирование вместе с PostgreSQL.
