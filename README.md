# Autopark for Bitrix24

Локальное серверное приложение для работы автопарка через Bitrix24.

Текущий рабочий прототип содержит:

- серверный API на Node.js;
- интерфейс с разделами по ролям;
- правила автомобилей, передач и путевых листов;
- исправление путевых листов водителем с историей версий и каскадным пересчетом;
- защищенные вложения путевых листов с локальным файловым хранилищем;
- создание и справочное редактирование автомобилей с аудитом;
- PostgreSQL, версионируемые миграции и транзакции;
- временный JSON-режим для запуска без установленной базы;
- изолированный адаптер Bitrix24;
- вход через Bitrix24 с серверным сеансом и управлением ролями;
- надежную очередь личных уведомлений Bitrix24;
- надежную очередь зеркальных карточек автомобилей Bitrix24;
- отчеты по путевым листам в CSV и XLSX;
- Docker Compose для приложения и PostgreSQL;
- отдельную production-конфигурацию, проверки готовности и резервное копирование;
- автоматические тесты.

## Быстрый запуск

```powershell
npm test
npm start
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:3000
```

По умолчанию без `DATABASE_URL` используется демонстрационное JSON-хранилище. Оно предназначено только для разработки.

Вложения сохраняются отдельно от JSON и PostgreSQL в каталоге `FILE_STORAGE_DIR` (по умолчанию `./data/files`). Клиент получает только служебные сведения о файле; внутренний ключ и путь хранения не выдаются. Разрешены JPEG, PNG, WebP, PDF, DOCX и XLSX размером до 10 МБ.

В локальном режиме `AUTH_MODE=local` сотрудника можно переключать в интерфейсе для проверки разных ролей. В рабочем режиме задайте `AUTH_MODE=bitrix`: приложение определит сотрудника через Bitrix24, создаст защищенный серверный сеанс и скроет переключатель ролей.

## Запуск с PostgreSQL

При установленном Docker:

```powershell
docker compose up --build
```

Приложение будет доступно на `http://127.0.0.1:3000`, PostgreSQL — на локальном порту `5432`. Миграции применяются автоматически при запуске приложения.

Без Docker задайте переменные вручную и запустите миграции:

```powershell
$env:STORAGE_DRIVER = 'postgres'
$env:DATABASE_URL = 'postgres://autopark:autopark@localhost:5432/autopark'
npm run db:migrate
npm start
```

## Переменные окружения

Пример находится в `.env.example`. Node.js сам по себе не загружает этот файл при обычной команде `npm start`: переменные нужно передать через PowerShell, Docker Compose или средство управления секретами на сервере.

Для реального Bitrix24 потребуются публичный HTTPS-адрес, домен портала, код и секрет локального приложения. Токены хранятся в зашифрованном виде; ключ шифрования остается только в переменных окружения.

Основной обработчик приложения в портале: `/bitrix/app`. Обработчик установки: `/bitrix/install`. Подробная последовательность настройки приведена в `docs/LOCAL_BITRIX_SETUP.md`.

Маршрут `/api/health` проверяет, что HTTP-процесс работает. Маршрут `/api/ready` дополнительно проверяет чтение настроенного хранилища и используется контейнером.
