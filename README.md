# Autopark for Bitrix24

Серверное приложение для учета автопарка через Bitrix24. Оно запускается напрямую на Node.js и PostgreSQL; Docker не требуется и не входит в проект.

В проекте есть интерфейс по ролям, автомобили и закрепления, передачи, путевые листы с историей правок, защищенные вложения, отчеты CSV/XLSX, аудит и очереди синхронизации с Bitrix24.

## Хранение данных

Рабочее хранилище — только PostgreSQL. Миграции в `migrations/` создают таблицы и ограничения. Файлы вложений расположены в `FILE_STORAGE_DIR`, а их метаданные и непрозрачные ключи — в базе. JSON-файлы не используются во время работы приложения.

`SEED_DEMO_DATA=true` создает демонстрационные данные только в новой пустой базе. Для реального запуска оставьте `false`.

## Локальный запуск

1. Установите Node.js 20.6+ и PostgreSQL 16+.
2. Создайте базу и пользователя:

```sql
CREATE ROLE autopark LOGIN PASSWORD 'задайте-надежный-пароль';
CREATE DATABASE autopark OWNER autopark;
```

3. Скопируйте `.env.example` в `.env` и укажите действительный `DATABASE_URL`.
4. Выполните:

```powershell
npm ci
npm run db:migrate
npm start
```

Приложение будет доступно по адресу `http://127.0.0.1:3000`. Команды npm автоматически загрузят `.env`, если файл существует.

Если требуется перенести прежний файл данных, импортируйте его один раз в пустую базу:

```powershell
$env:JSON_IMPORT_FILE = '.\\data\\autopark.json'
npm run db:import-json
```

Импорт не удаляет исходный файл. Для намеренной полной замены существующей базы используйте `npm run db:import-json -- --replace`.

## Проверки

```powershell
npm test
```

HTTP-интеграционный тест дополнительно запускается только при заданной отдельной тестовой БД `TEST_DATABASE_URL`.
